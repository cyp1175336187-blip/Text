# 1.0.7 凭据修复验证

本次在同一 1.0.7 版本内覆盖更新。密钥改存独立的 `local.text.menubar.credentials.v2` 记录，四项百度凭据合并保存；旧记录不自动读取、修改或删除。启动读取期间禁止认证界面，避免旧授权窗口反复出现。

## 验证结果

- 47 项隔离功能测试通过，覆盖多页 PDF、图片转换、服务解析、结果恢复、窗口缩放、进度、语言分组及凭据编码。
- 使用已知测试凭据的独立钥匙串测试通过：首次创建、同签名不同构建读取、更新、旧构建读取更新结果，以及不同签名拒绝读取；不显示授权 UI。
- 本机用户重新保存四项百度凭据后，独立进程读取成功；正常退出、重启后配置仍在，未出现旧授权窗口。
- 用户实际截图识字成功，随后翻译为英语成功。
- arm64 / x86_64 通用构建及签名完整性检查通过。

未完成 Apple Developer ID 签名和公证。Intel、其他设备、系统重启与未来升级场景未实机验证；本机结果不代表所有设备均已稳定。

发布内容仅包含程序、源码、说明、示例图、MIT 许可证与校验和。排除个人密钥、用户截图、账户配置、最近结果、缓存、签名私钥及本机钥匙串。
