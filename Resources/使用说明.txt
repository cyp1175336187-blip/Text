Text 1.0.7 · 使用说明

一、安装与启动
将 Text.app 拖到“应用程序”，双击打开。
Text 只驻留在屏幕顶部的 T 图标，不显示 Dock 图标，也不会启动浏览器。
点击 T 可打开四项菜单：截图识字、选择图片文件、识别结果、更多。
关闭结果或设置窗口不会退出软件；退出请使用“更多 → 退出软件”。

二、开始识字
截图：默认 ⌘1，也可从顶部菜单选择“截图识字”。拖动框选屏幕，Esc 取消。
文件：选择 PNG、JPG、HEIC、WebP 或 PDF；也可把文件拖到菜单栏 T 图标。
多页 PDF 按页码顺序识别，合并显示。每页消耗一次 OCR 调用。
每次新识别替换旧内容；只保留最近一次成功的原文、译文与原图，重启后可恢复。
一次最多 20 个文件，单文件最大 50 MB，单份 PDF 最多 100 页。加密 PDF 请先解锁。

三、结果窗口
软件自有窗口的默认尺寸统一为 270 × 203 点，可从边缘或角落拖动拉伸；控件会自动适应宽度，窗口较小时通过滚动查看内容。
偏好设置切换页签不会重置当前窗口尺寸，调整大小不会丢失未保存的输入。
结果窗口显示在 T 图标下方。深灰底、浅色文字，可拖动；拖动边缘可调整尺寸。
本次升级将旧版保存的结果窗口尺寸一次调整为 270 × 203 点；之后手动调整的大小仍会记住，下次主动显示定位到 T 图标下方。
选中文字后 ⌘C 复制。不会自动覆盖剪贴板。
左下角“文ᴬ”：首次开启翻译，此后点击会重新翻译，不会隐藏译文。
开启翻译后，原文在上，译文在下，目标语言可在底部选择；首次目标为简体中文。
翻译显示状态与目标语言会记住。再次识字时，若已开启翻译，将自动翻译。
原文与译文均可编辑；编辑原文不会自动覆盖译文，点击翻译按钮才更新。
底部中间按钮交换原文与译文，并切换目标语言。
右下角 ⋮：显示图片（⌘I）、自动隐藏（⌘H）、自动格式化、总在最前（⌘P）。
显示图片时左侧是原图，右侧是文字；多页 PDF 可用图片下方左右箭头翻页。
自动隐藏：点击窗口外隐藏，菜单“识别结果”或 ⇧⌘R 再次打开。
总在最前只控制显示时不被遮挡，同时开启自动隐藏时仍会隐藏。
自动格式化会合并段内换行、整理空格，保留段落空行。

四、偏好设置
通用：开机自启动（由你主动开启）、两种程序图标、版本信息。
图标切换改变应用内与运行时图标；安装包在 Finder 中使用圆形 T 图标。
账户：270 × 203 点的紧凑窗口，仅保留程序图标、Text · 服务账户、四项百度凭据、本月用量、免费用量保护和保存密钥。
识字固定使用百度通用文字识别（标准版），翻译固定使用百度通用文本翻译；密钥存入系统钥匙串。
百度翻译次数按本机发起的 API 请求计数；旧版没有记录次数，升级当月显示“更新后”，既有 OCR 次数和翻译字符数继续保留。
本月用量为 Text 本机统计的已发起调用；失败请求也计入保守统计，不是服务商实时账单。
快捷键：默认截图 ⌘1、显示结果 ⇧⌘R。点击输入框录入；× 清除，Esc 取消。
菜单展开后的 C / S / R 与全局快捷键相互独立。

五、尚未配置服务
没有密钥时，截图和选择文件等操作会显示“尚未配置服务”。不会填入模拟结果。
打开“更多 → 偏好设置 → 账户”，填写百度 OCR API Key、OCR Secret、翻译 APP ID 和翻译密钥，然后点击“保存密钥”。
具体申请步骤见随安装包提供的“配置指南.txt”。

六、用量保护
默认保护上限：百度 OCR 900 次/月、百度翻译 40,000 字符/月。翻译保护按字符计量，次数显示用于了解调用量。
这是基于免费优先的本机保守上限，不等于服务商免费额度，也不能保证整个账户不产生费用。
其他程序的调用、删除本地统计、服务商计费规则或账户状态均可能影响实际费用。
达到本机保护上限后暂停新调用。关闭保护需要你在账户页主动确认。

七、权限与故障
首次截图需允许 Text 屏幕录制权限；在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中配置，然后退出重开。
无网络、无权限、密钥失效等会显示简洁提示；错误原因会在识别结果窗口中显示。
Text 不要求辅助功能权限；系统保留或其他软件占用的快捷键需更换组合。

八、教程与反馈
“使用教程”打开本地说明；“意见反馈”打开本地表单，可保存为 TXT 后自行分享，不会自动发送。
最近结果保存在 ~/Library/Application Support/TextMenu/。重要内容可自行复制到文档备份。

1.0.7 外观调整：参考紧凑结果面板，使用不透明深灰渐变背景、浅色 13 点正文、细边框、小圆角与紧凑底部工具栏。
