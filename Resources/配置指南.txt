Text · 百度服务配置指南
核对日期：2026-10-21

当前软件未内置公共密钥。请使用你自己的服务账号；不要把密钥发到聊天、截图或反馈中。
配置入口：T → 更多 → 偏好设置 → 账户。

一、配置百度 OCR（标准版）
1. 登录百度智能云：https://cloud.baidu.com/
2. 完成所需个人实名认证，开通文字识别 OCR，领取账户实际享有的免费测试资源。
3. 创建名为 Text 的文字识别应用，授权“通用文字识别（标准版）”，取得 API Key 与 Secret Key。
4. 分别填入“百度 OCR API Key”和“百度 OCR Secret”，保存。
5. 软件固定使用百度标准版，选择一张普通图片测试识字。
使用接口：通用文字识别（标准版）general_basic。
官方资料：https://ai.baidu.com/ai-doc/OCR/zk3h7xz52

二、配置百度翻译
1. 登录百度翻译开放平台：https://fanyi-api.baidu.com/
2. 开通“通用文本翻译”服务，按你的实际需求选择标准版或个人认证高级版。
3. 获取翻译 APP ID 与密钥；它们与百度 OCR 的密钥不是同一组。
4. 填入“百度翻译 APP ID”和“百度翻译密钥”，保存。
5. 软件固定使用百度翻译，在结果窗口选择英语并点击翻译按钮测试。
百度翻译支持本版提供的 28 种常见目标语言。
官方资料：https://fanyi-api.baidu.com/access/0/1
https://fanyi-api.baidu.com/doc/21

三、免费额度与费用参考
百度 OCR 标准版：个人认证免费测试资源 1,000 次/月；按量首档 0.005 元/次；预付费次数包 1 万次 50 元，购买后一年内有效。是否启用付费由你另行决定。
百度翻译：标准版每月 50,000 字符免费；个人认证高级版每月 1,000,000 字符免费；超出部分常用价 49 元/百万字符。
报价会调整，账户资格也可能不同；开户前以官方控制台显示为准。软件不会为你自动开通付费服务。

Text 仅记录本机发起的 OCR 次数和翻译 Unicode 字符数，失败与重试也可能消耗免费资源。
不进行自动重试、双引擎并发调用或自动付费切换。
